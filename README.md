# Hey, I'm Duke.

I build automation tools and mod games. Based in Australia, usually down a rabbit hole involving AI, a game server, or something my tabletop group wanted to try.

I've been working with machine learning since 2016. I'm passionate about open source and helping people.

[Browse my repos](https://github.com/DukeVenator?tab=repositories) · [Projects and mods](#projects-and-mods) · [Talk code](#get-in-touch)

## What I'm into

- **Automation & AI** — building workflows and exploring where AI helps, where it doesn't, and what can go wrong.
- **Game tools & modding** — Foundry VTT modules, server utilities, and tweaks for the games I play.
- **Learning by building** — side projects, experiments, and the occasional very specific fix.

## Projects and mods

A wide range of Foundry VTT modules and mods for various games.
